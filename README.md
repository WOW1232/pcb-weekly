# PCB 동종업종 주가 및 시가총액 – 자동 업데이트

- 사이트: https://wow1232.github.io/pcb-weekly/
- 금 16:00 1차 수집 → 금 16:30 중국 포함 최종 확정. 금요일 휴장 시 그 주 마지막 거래일 18:00에 처리
- 공시 게시판·주식수 점검: 매주 목 18:00 (Claude 예약 작업)
- 엑셀은 저장하지 않음. 사이트의 "종가 22개 복사" 버튼으로 회사 엑셀에 붙여넣기

## 자주 하는 일
| 하고 싶은 것 | 방법 |
|---|---|
| 이번 주 건너뛰기 | `config/calendar.json` 의 `skip_dates` 에 날짜 추가 |
| 보고일이 아닌 날 강제 생성 | Actions → "주간 종가 업데이트" → Run workflow → mode=force, 날짜 입력 |
| 주식수 변경 | `config/companies.json` 해당 회사 `shares_k`(천주) 수정 |

수집 실패 시 해당 실행이 실패로 표시되고 GitHub에서 메일이 옵니다. 사이트 상단에도 빨간 경고가 뜹니다.
